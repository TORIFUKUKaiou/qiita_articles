## 世界的なプロジェクトへの貢献

Qiitaで発信するうちに、発信癖がつきました。そう、クセです。
ついには、世界的なプロジェクトへ貢献するに至りました。
その一部をご紹介します。

### Elixir

プログラミング言語です。Erlang の仮想マシン（BEAM）の上で動く関数型言語で、大量の処理を並行して動かすことと、障害が起きても止まりにくいことが特徴です。

- https://github.com/elixir-lang/elixir/pull/11039
- https://github.com/elixir-lang/elixir/pull/11046

### Phoenix

Elixir の Web アプリケーションフレームワークです。Phoenix LiveView を使うと、JavaScript をほとんど書かずに、サーバー側のコードだけでリアルタイムに画面が変わる Web アプリを作れるのが特徴です。

- https://github.com/phoenixframework/phoenix_live_view/commit/46d870c9f0101dcdf721807053c9ca2bd0c9f766

### Nerves

Elixir で組込み・IoT 機器のソフトウェアを作るためのフレームワークです。Raspberry Pi などで、最小限の Linux の上に Elixir のアプリケーションをそのまま載せて動かせるのが特徴です。

- https://github.com/nerves-project/nerves_bootstrap/pull/163
- https://github.com/nerves-project/nerves_bootstrap/pull/266
- https://github.com/nerves-project/nerves_bootstrap/pull/267
- https://github.com/nerves-networking/vintage_net/pull/538

### Livebook

Elixir のコードを書いて、その場で実行結果を確かめられるノートブックです。Jupyter に近いもので、Nerves Livebook を使うと Raspberry Pi などの機器の上で動かせるのが特徴です。

- https://github.com/livebook-dev/nerves_livebook/pull/148

### Ecto

Elixir からデータベースを扱うためのライブラリです。Elixir の文法のままクエリを組み立てられることと、データの検証（バリデーション）の仕組みを備えていることが特徴です。

- https://github.com/elixir-ecto/ecto/pull/3826

### AWS CDK

AWS のインフラをコードで定義するためのフレームワークです。TypeScript や Python などのふだん使っているプログラミング言語で書いたコードから、CloudFormation のテンプレートを生成できるのが特徴です。

- https://github.com/aws/aws-cdk-cli/pull/1644
